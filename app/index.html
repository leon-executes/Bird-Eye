Resource policy

Model connections

Endpoints use the vision Chat Completions protocol. Local addresses stay local. Remote URLs need HTTPS and an explicit allowRemote: true; images will leave this computer.

Keys are stored only in the ignored local settings file. “Specialist” is a user declaration, not a certification. The controller does not unload externally managed servers.

PROVENANCE / LIMITS / REPRODUCIBILITY

Know what is in the test.

A small, deliberately varied engineering pack—not a population-representative benchmark. Known training overlap can inflate results. Real datasets, product-derived temperatures, and synthetic controls are kept distinct.

How to read an assessment

CLEAR Visibly supported according to the model; still reviewable.

LIKELY Best interpretation with a meaningful alternative.

TENTATIVE Weak evidence, numerical visual estimate, or unresolved ambiguity.

UNKNOWN Missing, contradictory, or unsupported evidence.

These are qualitative evidence grades, not calibrated probabilities. The same model in several roles is correlated evidence. Satellite-scale thermal images cannot inherit the resolution of an RGB partner. Brightness alone is not temperature; a temperature anomaly alone is not geothermal attribution.

Release contents

The release includes attributed public sample imagery. Personal imports, private reports, settings and model weights are excluded from the public source archive. Downloaded models retain their own licenses.
