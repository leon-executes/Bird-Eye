# Bird Eye 1.0.2

Complete council setup restores EarthDial, Qwen3.5, CapRL and RemoteCLIP from 12 lossless, checksum-verified model parts below 2 GB each. Public app and model parts exclude the thermal detector. The personal edition includes a separately launched thermal provider for local testing.

An optional loopback gateway requests classes, candidate counts and boxes. The final master must record decisions; accepted object contributions cannot silently disappear from findings. Focused inspection uses enlarged original pixels. Two-frame tests show useful candidate/count retention but continued uncertainty and mistakes in final scene interpretation.

A simplified transparent emblem, warmer Earthrise palette, responsive full-width workspace and per-image expanded viewer improve the desktop presentation.

Extract the Windows ZIP; run Setup models.cmd; open Bird Eye.exe. Offline: place all model parts beside the executable first. See docs/MODEL_DISTRIBUTION.md and docs/EXTERNAL_DETECTOR.md.
